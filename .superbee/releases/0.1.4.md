# Superbee 0.1.4

Superbee 0.1.4 brings additive recipe evolution, a read-only publication facade, and native Windows support to the stable channel.

This release was published on 2026-08-31 as `superbee@0.1.4` under
the npm `latest` tag.

# What changed

- Installed recipes can be evolved additively through a reviewed plan and state-bound apply step.
- The stable package exports read-only publication snapshot and bridge APIs for trusted external publishers.
- Installation, private-state handling, setup, and host integration now support Windows alongside macOS and Linux.
- Setup can report bounded, agent-executable remediation actions while preserving human approval and restart boundaries.

# What you need to do

New users can install superbee@latest; existing users should reinstall the latest stable package, rerun superbee setup for each configured host, and restart any host whose setup report requires it.

# Compatibility

Requires Node.js >=20 and supports darwin, linux, and win32. Host setup covers Codex, Claude Code, Claude Desktop, and OpenCode. Superbee remains pre-1.0, so use the release and migration guidance before upgrading automated workflows.

# Recovery

Pin superbee@0.1.3 and rerun setup to restore the previous stable CLI and host integration. If recipe state changes after planning, discard the stale token and run recipe evolve again before applying.
